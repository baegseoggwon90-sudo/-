# 한국 영상 교체기 (kbroll)

나레이션 영상 중간중간 **외국 영상이 나오는 구간의 화면만 한국 영상으로 바꿔 주는** 프로그램입니다.

- 🎙️ **음성(나레이션)**: 원본 그대로입니다. 오디오를 재인코딩하지 않고 그대로 복사하므로 원본과 완전히 같습니다.
- 💬 **자막**: 원본 그대로입니다. 화면에 박힌 자막은 원본에서 자막 부분만 떼어서 바뀐 화면 위에 다시 얹습니다.
- 🎬 **나머지 화면**: 고르지 않은 구간은 원본 화면 그대로입니다.
- 🌐 **인터넷 서버**: 비밀번호 로그인을 켜고 서버에 올려 어디서나 인터넷 주소로 쓸 수 있습니다.
- 🎞️ **CapCut 초안**: 완성 MP4 대신 CapCut 에서 계속 편집할 수 있는 프로젝트로도 만들 수 있습니다 (pyCapCut).
- 🤖 **AI 자동 추천**: 나레이션 내용에 안 맞는 장면을 찾아 내 자료·픽사베이에서 가장 잘 맞는 한국 영상으로 골라 줍니다.

```
원본:   [한국 화면][외국 화면 ✗][한국 화면][외국 화면 ✗]...   ← 나레이션+자막
결과:   [한국 화면][한국 영상 ✓][한국 화면][한국 영상 ✓]...   ← 나레이션+자막 (그대로)
```

---

## 1. 설치

1. **Python 3.9 이상**을 설치합니다 (https://www.python.org/downloads/ , 설치할 때 *Add python.exe to PATH* 체크).
2. 이 폴더에서 한 번만 실행:
   ```
   pip install -r requirements.txt
   ```
   ffmpeg 가 같이 설치되므로 따로 설치할 필요가 없습니다. (이미 ffmpeg 가 설치되어 있으면 그것을 씁니다.)

**Windows** 에서는 `start_windows.bat` 을 더블클릭하면 설치부터 실행까지 알아서 합니다.

## 2. 준비물

- **원본 영상** (예: `내영상.mp4`)
- **한국 영상 폴더**: 교체에 쓸 한국 영상(`.mp4`, `.mov` 등) 또는 사진(`.jpg`, `.png`)을 넣은 폴더
  - 여러 개를 넣으면 순서대로 돌아가며 사용합니다. 같은 영상을 다시 쓸 때는 이전에 쓴 부분 다음부터 이어서 씁니다.
  - 구간보다 짧은 영상은 반복 재생됩니다.
  - 크기/비율이 달라도 원본 화면 크기에 맞춰 자동으로 채웁니다 (가장자리를 잘라내서 맞춤).

## 3. 사용법 (웹 화면)

```
python -m kbroll
```

실행하면 브라우저에 편집 화면(`http://127.0.0.1:8765`)이 자동으로 열립니다. 끝낼 때는 실행한 검은 창에서 `Ctrl+C`를 누르세요.
(Windows 는 `start_windows.bat` 더블클릭)

1. **영상 올리기** — 원본 영상과 한국 영상/사진을 끌어다 놓습니다.
2. **외국 영상 장면 고르기** — *장면 분석* 을 누르면 컷 단위로 나뉩니다.
   외국 영상이 나오는 장면을 클릭하면 빨간색으로 표시되고, 아래 타임라인에도 교체 구간이 빨갛게 보입니다.
   - Shift+클릭: 범위 선택
   - 장면마다 쓸 한국 영상을 고를 수 있습니다 (기본: 자동)
   - 장면 구분이 안 맞으면 플레이어를 움직여 *시작/끝 ⟵ 현재 위치* 로 구간을 직접 추가
3. **자막 지키기** — 자막 처리 방식과 자막 영역(플레이어에 노란 점선으로 표시)을 맞추고,
   *현재 위치 미리보기* 로 교체된 화면에 자막이 잘 남는지 확인합니다.
4. **영상 만들기** — 먼저 *빠른 확인용* 으로 만들어 확인한 뒤 *고화질* 로 최종본을 만드세요.
   결과는 화면에서 바로 재생·다운로드할 수 있습니다.

- 올린 파일과 결과물은 **홈 폴더의 `kbroll_작업` 폴더**에 저장됩니다 (`--workdir 폴더` 로 변경 가능).
  고른 장면·설정도 저장되어 있어서 창을 닫았다가 다시 열어도 이어서 작업할 수 있습니다.
- 파일은 인터넷으로 나가지 않고 이 PC 안에서만 처리됩니다.
- 같은 공유기(와이파이)의 휴대폰·태블릿에서 보고 싶다면 `python -m kbroll web --host 0.0.0.0` 으로 실행하고
  `http://이PC의IP:8765` 로 접속합니다. 이 경우 같은 네트워크의 누구나 접속할 수 있으니 집 네트워크에서만 쓰세요.
- 예전 창 프로그램은 `python -m kbroll gui` 로 실행할 수 있습니다.

## 🤖 AI 자동 추천 (내 자료 · 픽사베이에서 자동으로 찾아 넣기)

나레이션이 무엇을 소개하는지 이해해서, **외국 영상이거나 내용과 맞지 않는 장면**을 찾고,
**내 자료(올린 한국 영상)**와 **픽사베이 무료 영상**을 검색해 **가장 잘 맞는 영상**으로 바꿔 넣습니다.

### 준비 (처음 한 번)
웹 화면 오른쪽 위 **⚙ AI 설정**에서 키를 넣습니다.
- **Claude API 키**: <https://console.anthropic.com/settings/keys> 에서 발급합니다. 장면을 판단하고 영상을 고르는 데 쓰이며, 쓴 만큼 요금이 나갑니다.
  10분 영상(장면 100개 정도) 한 편에 대략 1~3달러입니다. 장면 수와 교체할 장면 수에 따라 달라집니다.
- **픽사베이 API 키**: <https://pixabay.com/api/docs/> 에서 가입하면 무료로 받을 수 있습니다.

키는 이 PC의 작업 폴더(`settings.json`)에만 저장됩니다. 환경변수 `ANTHROPIC_API_KEY`, `PIXABAY_API_KEY` 로 넣어도 됩니다.

### 사용법
1. 원본 영상을 올립니다. 내 자료가 있으면 한국 영상 칸에 같이 올립니다.
2. **나레이션 대본**을 넣습니다. 하나만 고르면 됩니다.
   - 가장 정확함: **자막 파일(SRT/VTT)** 올리기
   - **음성 자동 인식**: `pip install faster-whisper` 를 설치하면 켤 수 있습니다.
   - 둘 다 없으면 Claude 가 화면에 박힌 자막을 직접 읽어서 판단합니다.
3. 찾을 곳(내 자료 / 픽사베이)과 맞춤 기준을 고르고 **AI 자동 추천 시작**을 누릅니다.
4. 끝나면 교체할 장면이 빨간색으로 표시됩니다. 장면 카드마다 아래 내용이 나오고, 카드에 마우스를 올리면 나레이션과 판단 이유가 보입니다.
   - AI 판단: 외국 영상 / 내용 불일치 / 그대로 두기
   - 필요한 화면 설명
   - 고른 영상과 점수
5. 마음에 안 드는 장면은 클릭해서 빼거나 다른 영상을 고른 뒤 **영상 만들기**를 누릅니다.
   **추천 후 바로 영상 만들기**를 켜 두면 추천이 끝나자마자 영상까지 만들어집니다.

### 알아두기
- 내 자료가 픽사베이 영상과 비슷하게 잘 맞으면 내 자료를 먼저 씁니다. 내 자료의 내용 설명은 한 번 만들면 저장해 두고 다시 씁니다.
- 픽사베이 영상은 원본 해상도에 맞는 크기로 내려받아 한국 영상 폴더에 `pixabay_번호.mp4` 로 저장됩니다.
  영상 카드의 `Pixabay · 올린사람` 링크로 원래 페이지를 확인할 수 있습니다.
  픽사베이 영상은 상업적으로도 무료로 쓸 수 있고 출처 표시는 필수가 아니지만, 표시해 주면 좋습니다.
- 외국 영상인지는 간판 글자, 번호판, 랜드마크, 건축 같은 **배경 단서로만** 판단합니다. 사람의 외모로는 판단하지 않습니다.
- 맞춤 기준을 **엄격하게**로 두면 잘 맞는 영상이 없는 장면은 바꾸지 않고 그대로 둡니다.
- 모델은 AI 설정에서 바꿀 수 있습니다 (기본 `claude-opus-5`).

## 🎞️ CapCut 초안으로 만들기 (pyCapCut)

완성된 MP4 대신, **CapCut 에서 열어 계속 편집할 수 있는 초안(프로젝트)**을 만들 수 있습니다.
[pyCapCut](https://github.com/GuanYixuan/pycapcut) 으로 CapCut 초안 폴더에 바로 저장합니다.

**웹 화면에서:** ④ 영상 만들기 → 만들 형태 **CapCut 초안** → **CapCut 초안 만들기**
(AI 자동 추천의 *추천 후 바로 영상 만들기* 를 켜면 추천이 끝나자마자 초안까지 만들어집니다.)

**초안 폴더**는 자동으로 찾습니다. 못 찾으면 **CapCut > 설정 > 초안 위치**의 경로를 ⚙ AI 설정의 *CapCut 초안 폴더* 에 넣어주세요.
- Windows 기본: `C:\Users\<이름>\AppData\Local\CapCut\User Data\Projects\com.lveditor.draft`
- Mac 기본: `~/Movies/CapCut/User Data/Projects/com.lveditor.draft`

만들어지는 초안의 트랙 (아래 → 위)

| 트랙 | 내용 |
|---|---|
| 원본영상 | 원본 영상 전체. **나레이션 음성도 이 트랙 그대로** |
| 한국영상 | 교체 구간에만 한국 영상 (소리 끔, 화면 꽉 채우게 확대, 짧으면 반복) |
| 자막보존 | 교체 구간의 원본 자막만 떼어 낸 조각 (*글자만* = 투명 배경 ProRes 영상 / *자막 띠* = 띠 전체) |
| 자막 | *CapCut 텍스트 자막으로 넣기* 를 고른 경우: 자막 파일의 문장을 CapCut 텍스트로 넣음 (글꼴·색을 CapCut 에서 바꿀 수 있음) |

- CapCut 을 열면 홈 화면 초안 목록에 나타납니다. 안 보이면 CapCut 을 완전히 껐다가 다시 켜세요.
- 한국 영상은 CapCut 에서 끌어서 위치를 바꾸거나 다른 영상으로 바꿀 수 있습니다. 확인 후 CapCut 에서 **내보내기(Export)** 하세요.
- 초안은 작업 폴더(`kbroll_작업`)의 원본·한국 영상 파일을 그대로 가리킵니다. **작업 폴더를 지우거나 옮기면 CapCut 에서 '미디어 없음'으로 나옵니다.**
- 명령어로: `python -m kbroll capcut 원본.mp4 segments.csv --clips 한국영상 [--drafts 초안폴더] [--subtitle key|band|text|none] [--srt 자막.srt]`

## 🌐 인터넷 서버에 올리기 (어디서나 인터넷 주소로 접속)

PC 를 켜 두지 않아도 휴대폰·다른 컴퓨터에서 `https://….onrender.com` 같은 주소로 쓸 수 있게 서버에 올릴 수 있습니다.
서버 모드에서는 다음이 달라집니다.

- **비밀번호 로그인**이 켜집니다. 비밀번호 없이는 서버가 시작되지 않습니다. 로그인하지 않으면 영상·설정·API 키에 접근할 수 없습니다.
- **CapCut 초안은 ZIP 으로 내려받습니다.** 서버는 내 PC 의 CapCut 폴더에 직접 넣을 수 없기 때문입니다.
  1. ⚙ 설정에 **내 PC 의 CapCut 초안 폴더** 경로를 한 번 적어 둡니다.
  2. ZIP 을 내려받아 그 폴더에 압축을 풉니다.
  3. CapCut 을 껐다 켜면 초안 목록에 나타납니다. ZIP 안에 원본·한국 영상이 모두 들어 있습니다.

### Render 로 올리기 (가장 간단)
1. <https://render.com> 에 GitHub 계정으로 가입합니다.
2. **New → Blueprint** 를 누르고 이 저장소를 고릅니다. 저장소에 있는 `render.yaml` 을 Render 가 자동으로 읽습니다.
3. `KBROLL_PASSWORD` 칸에 로그인 비밀번호를 넣고 **Apply** 를 누릅니다. 추측하기 어려운 긴 비밀번호를 쓰세요.
4. 몇 분 뒤 나오는 `https://kbroll-….onrender.com` 주소로 접속해 로그인합니다.

알아두기
- **요금**: 올린 영상을 보관하려면 영구 디스크가 필요하고, Render 에서 영구 디스크는 유료 플랜에서만 쓸 수 있습니다.
  `render.yaml` 기본값(Starter 플랜 + 20GB 디스크)은 대략 월 10달러 안팎입니다. 정확한 금액은 Render 요금표를 확인하세요.
  무료 플랜은 디스크가 없어 서버가 다시 시작되면 올린 파일이 사라집니다.
- **속도**: 기본 플랜은 CPU 가 작아서 MP4 만들기가 PC 보다 훨씬 느립니다. 10분짜리 1080p 영상이면 수십 분이 걸릴 수 있습니다.
  *빠른 확인용* 화질이나 **CapCut 초안**(영상을 새로 인코딩하지 않아 빠름)을 쓰거나, Render 에서 더 큰 플랜을 고르세요.
- 영상을 인터넷으로 올리고 내려받아야 하므로 큰 파일은 인터넷 속도에 따라 시간이 걸립니다.

### 다른 서버(Docker)에 올리기
Docker 가 되는 서버면 어디든 됩니다.
```bash
docker build -t kbroll .
docker run -d -p 80:8765 -e KBROLL_PASSWORD='긴-비밀번호' -v kbroll-data:/data kbroll
```
HTTPS 는 서버 앞단(Cloudflare, Nginx, 호스팅 업체 기능 등)에서 켜 주세요.
직접 실행할 때는 `KBROLL_PASSWORD=비밀번호 python -m kbroll web --public` 으로 서버 모드를 켤 수 있습니다.

## 4. 사용법 (명령어)

```bash
# 웹 화면 없이 명령어만으로 쓰기
# 1) 장면 분석 → 검토 페이지 (kbroll_work/review.html) 가 열림
python -m kbroll scan 내영상.mp4 --clips 한국영상

# 2) 교체해서 새 영상 만들기
python -m kbroll replace 내영상.mp4 segments.csv --clips 한국영상 -o 결과.mp4

# 구간을 바로 적어도 됩니다 (1분10초~1분18초, 2분~2분5초)
python -m kbroll replace 내영상.mp4 "1:10-1:18;2:00-2:05" --clips 한국영상
```

### segments.csv 형식

```csv
start,end,clip,clip_start
00:01:10.5,00:01:18,,
83.2,90,seoul_night.mp4,12
```

| 칸 | 뜻 |
|---|---|
| `start`, `end` | 교체할 구간. `83.2`(초), `1:23.2`(분:초), `00:01:23.2`(시:분:초) 모두 가능 |
| `clip` | (선택) 이 구간에 쓸 한국 영상 파일 이름. 비우면 폴더에서 자동 선택 |
| `clip_start` | (선택) 한국 영상의 몇 초 지점부터 쓸지 |

## 5. 자막 보존 설정

화면에 박힌 자막을 지키는 방식을 고를 수 있습니다 (`--subtitle`, 창 프로그램의 *자막 처리*).

| 방식 | 언제 | 설명 |
|---|---|---|
| `key` (기본) | 흰색/노란색 글자 + 검은 테두리 자막 | 자막 글자와 테두리만 뽑아서 한국 영상 위에 얹습니다 |
| `band` | 자막 뒤에 반투명/검정 **박스**가 있는 자막 | 자막 영역 띠 전체를 원본 그대로 얹습니다 |
| `none` | 자막이 화면에 없거나 별도 자막 파일(.srt)인 경우 | 화면만 바꿉니다 (영상 안의 자막 트랙은 그대로 복사됨) |

- **자막 영역** `--sub-region x,y,w,h` : 화면 대비 비율. 기본값 `0,0.72,1,0.28` = 화면 아래쪽 28%.
  자막이 더 위에 있으면 `0,0.6,1,0.4` 처럼 넓혀 주세요.
- `key` 방식 세부 조정
  - `--sub-threshold 200` : 이 밝기 이상을 글자로 봅니다. 노란 자막이 잘 안 잡히면 `170` 정도로 낮추세요.
  - `--sub-outline 4` : 글자 테두리 두께(px). 테두리가 잘리면 늘리세요.
  - `--sub-dark 80` : 글자 근처에 이만큼 어두운 테두리가 있어야 글자로 인정합니다 (밝은 하늘·벽이 딸려 오는 것 방지).
    테두리 없는 자막이면 `0` 으로 끄세요.

> 💡 먼저 짧은 구간 하나만 `--preset ultrafast` 로 만들어 보고 자막이 잘 보존되는지 확인한 뒤 전체를 만들면 편합니다.

## 6. 기타 옵션

| 옵션 | 설명 |
|---|---|
| `--shuffle` / `--seed 숫자` | 한국 영상을 무작위 순서로 사용 (seed 를 주면 매번 같은 순서) |
| `--crf 18` | 화질 (낮을수록 고화질·큰 파일, 보통 16~23) |
| `--preset medium` | 인코딩 속도 (`ultrafast` 빠름 ~ `slow` 고효율) |
| `scan --threshold 0.3` | 장면 전환 민감도. 장면이 너무 적게 나뉘면 `0.2`, 너무 잘게 나뉘면 `0.4` |

## 참고

- 화면 합성 때문에 영상(비디오)은 다시 인코딩합니다. 기본값 `--crf 18` 은 눈으로 구분이 어려운 고화질입니다. 오디오는 재인코딩하지 않습니다.
- `key` 방식은 밝은 글자를 기준으로 뽑기 때문에, 자막 바로 옆의 매우 밝은 원본 배경이 글자 주변에 약간 남을 수 있습니다. 그럴 때는 `band` 방식을 쓰거나 `--sub-outline` 을 줄여 보세요.
