# 한국 영상 교체기 (kbroll)

나레이션 영상 중간중간 **외국 영상이 나오는 구간의 화면만 한국 영상으로 바꿔 주는** 프로그램입니다.

- 🎙️ **음성(나레이션)**: 원본 그대로입니다. 오디오를 재인코딩하지 않고 그대로 복사하므로 원본과 완전히 같습니다.
- 💬 **자막**: 원본 그대로입니다. 화면에 박힌 자막은 원본에서 자막 부분만 떼어서 바뀐 화면 위에 다시 얹습니다.
- 🎬 **나머지 화면**: 고르지 않은 구간은 원본 화면 그대로입니다.

```
원본:   [한국 화면][외국 화면 ✗][한국 화면][외국 화면 ✗]...   ← 나레이션+자막
결과:   [한국 화면][한국 영상 ✓][한국 화면][한국 영상 ✓]...   ← 나레이션+자막 (그대로)
```

---

## 1. 설치

1. **Python 3.9 이상**을 설치합니다 (https://www.python.org/downloads/ , 설치할 때 *Add python.exe to PATH* 체크).
2. 이 폴더에서 한 번만 실행:
   ```
   pip install -r requirements.txt
   ```
   ffmpeg 가 같이 설치되므로 따로 설치할 필요가 없습니다. (이미 ffmpeg 가 설치되어 있으면 그것을 씁니다.)

**Windows** 에서는 `start_windows.bat` 을 더블클릭하면 설치부터 실행까지 알아서 합니다.

## 2. 준비물

- **원본 영상** (예: `내영상.mp4`)
- **한국 영상 폴더**: 교체에 쓸 한국 영상(`.mp4`, `.mov` 등) 또는 사진(`.jpg`, `.png`)을 넣은 폴더
  - 여러 개를 넣으면 순서대로 돌아가며 사용합니다. 같은 영상을 다시 쓸 때는 이전에 쓴 부분 다음부터 이어서 씁니다.
  - 구간보다 짧은 영상은 반복 재생됩니다.
  - 크기/비율이 달라도 원본 화면 크기에 맞춰 자동으로 채웁니다 (가장자리를 잘라내서 맞춤).

## 3. 사용법 (웹 화면)

```
python -m kbroll
```

실행하면 브라우저에 편집 화면(`http://127.0.0.1:8765`)이 자동으로 열립니다. 끝낼 때는 실행한 검은 창에서 `Ctrl+C`를 누르세요.
(Windows 는 `start_windows.bat` 더블클릭)

1. **영상 올리기** — 원본 영상과 한국 영상/사진을 끌어다 놓습니다.
2. **외국 영상 장면 고르기** — *장면 분석* 을 누르면 컷 단위로 나뉩니다.
   외국 영상이 나오는 장면을 클릭하면 빨간색으로 표시되고, 아래 타임라인에도 교체 구간이 빨갛게 보입니다.
   - Shift+클릭: 범위 선택
   - 장면마다 쓸 한국 영상을 고를 수 있습니다 (기본: 자동)
   - 장면 구분이 안 맞으면 플레이어를 움직여 *시작/끝 ⟵ 현재 위치* 로 구간을 직접 추가
3. **자막 지키기** — 자막 처리 방식과 자막 영역(플레이어에 노란 점선으로 표시)을 맞추고,
   *현재 위치 미리보기* 로 교체된 화면에 자막이 잘 남는지 확인합니다.
4. **영상 만들기** — 먼저 *빠른 확인용* 으로 만들어 확인한 뒤 *고화질* 로 최종본을 만드세요.
   결과는 화면에서 바로 재생·다운로드할 수 있습니다.

- 올린 파일과 결과물은 **홈 폴더의 `kbroll_작업` 폴더**에 저장됩니다 (`--workdir 폴더` 로 변경 가능).
  고른 장면·설정도 저장되어 있어서 창을 닫았다가 다시 열어도 이어서 작업할 수 있습니다.
- 파일은 인터넷으로 나가지 않고 이 PC 안에서만 처리됩니다.
- 같은 공유기(와이파이)의 휴대폰·태블릿에서 보고 싶다면 `python -m kbroll web --host 0.0.0.0` 으로 실행하고
  `http://이PC의IP:8765` 로 접속합니다. 이 경우 같은 네트워크의 누구나 접속할 수 있으니 집 네트워크에서만 쓰세요.
- 예전 창 프로그램은 `python -m kbroll gui` 로 실행할 수 있습니다.

## 4. 사용법 (명령어)

```bash
# 웹 화면 없이 명령어만으로 쓰기
# 1) 장면 분석 → 검토 페이지 (kbroll_work/review.html) 가 열림
python -m kbroll scan 내영상.mp4 --clips 한국영상

# 2) 교체해서 새 영상 만들기
python -m kbroll replace 내영상.mp4 segments.csv --clips 한국영상 -o 결과.mp4

# 구간을 바로 적어도 됩니다 (1분10초~1분18초, 2분~2분5초)
python -m kbroll replace 내영상.mp4 "1:10-1:18;2:00-2:05" --clips 한국영상
```

### segments.csv 형식

```csv
start,end,clip,clip_start
00:01:10.5,00:01:18,,
83.2,90,seoul_night.mp4,12
```

| 칸 | 뜻 |
|---|---|
| `start`, `end` | 교체할 구간. `83.2`(초), `1:23.2`(분:초), `00:01:23.2`(시:분:초) 모두 가능 |
| `clip` | (선택) 이 구간에 쓸 한국 영상 파일 이름. 비우면 폴더에서 자동 선택 |
| `clip_start` | (선택) 한국 영상의 몇 초 지점부터 쓸지 |

## 5. 자막 보존 설정

화면에 박힌 자막을 지키는 방식을 고를 수 있습니다 (`--subtitle`, 창 프로그램의 *자막 처리*).

| 방식 | 언제 | 설명 |
|---|---|---|
| `key` (기본) | 흰색/노란색 글자 + 검은 테두리 자막 | 자막 글자와 테두리만 뽑아서 한국 영상 위에 얹습니다 |
| `band` | 자막 뒤에 반투명/검정 **박스**가 있는 자막 | 자막 영역 띠 전체를 원본 그대로 얹습니다 |
| `none` | 자막이 화면에 없거나 별도 자막 파일(.srt)인 경우 | 화면만 바꿉니다 (영상 안의 자막 트랙은 그대로 복사됨) |

- **자막 영역** `--sub-region x,y,w,h` : 화면 대비 비율. 기본값 `0,0.72,1,0.28` = 화면 아래쪽 28%.
  자막이 더 위에 있으면 `0,0.6,1,0.4` 처럼 넓혀 주세요.
- `key` 방식 세부 조정
  - `--sub-threshold 200` : 이 밝기 이상을 글자로 봅니다. 노란 자막이 잘 안 잡히면 `170` 정도로 낮추세요.
  - `--sub-outline 4` : 글자 테두리 두께(px). 테두리가 잘리면 늘리세요.
  - `--sub-dark 80` : 글자 근처에 이만큼 어두운 테두리가 있어야 글자로 인정합니다 (밝은 하늘·벽이 딸려 오는 것 방지).
    테두리 없는 자막이면 `0` 으로 끄세요.

> 💡 먼저 짧은 구간 하나만 `--preset ultrafast` 로 만들어 보고 자막이 잘 보존되는지 확인한 뒤 전체를 만들면 편합니다.

## 6. 기타 옵션

| 옵션 | 설명 |
|---|---|
| `--shuffle` / `--seed 숫자` | 한국 영상을 무작위 순서로 사용 (seed 를 주면 매번 같은 순서) |
| `--crf 18` | 화질 (낮을수록 고화질·큰 파일, 보통 16~23) |
| `--preset medium` | 인코딩 속도 (`ultrafast` 빠름 ~ `slow` 고효율) |
| `scan --threshold 0.3` | 장면 전환 민감도. 장면이 너무 적게 나뉘면 `0.2`, 너무 잘게 나뉘면 `0.4` |

## 참고

- 화면 합성 때문에 영상(비디오)은 다시 인코딩합니다. 기본값 `--crf 18` 은 눈으로 구분이 어려운 고화질입니다. 오디오는 재인코딩하지 않습니다.
- `key` 방식은 밝은 글자를 기준으로 뽑기 때문에, 자막 바로 옆의 매우 밝은 원본 배경이 글자 주변에 약간 남을 수 있습니다. 그럴 때는 `band` 방식을 쓰거나 `--sub-outline` 을 줄여 보세요.
